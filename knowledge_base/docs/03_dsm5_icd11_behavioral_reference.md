# DSM-5-TR & ICD-11 Behavioral Reference Layer (Simulation Adaptation)
**Standard:** Clinical Reference Criteria  
**Domain:** Affective Instability & Avoidance Features  
**Classification:** Reference Layer (Simulation Only — Non-Diagnostic)  

## Reference Protocol
Used exclusively as an architectural benchmark for modeling synthetic affective dysregulation, acute social stress responses, and cognitive avoidance loops.

### Key Simulation Metrics:
1. **Affective Lability:** Rate of oscillation between high valence and extreme distress under peer rejection stimuli.
2. **Stress-Induced Dissociation:** Latency in sensory response when environmental threat exceeds coping threshold.
3. **Compulsive Social Avoidance:** Prolonged withdrawal from peer clusters following public humiliation.
